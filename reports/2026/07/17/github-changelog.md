## Advanced search for Projects is generally available

- 公開日 (UTC): `2026-07-16 19:07:14`
- リンク: <https://github.blog/changelog/2026-07-16-advanced-search-for-projects-is-generally-available>

GitHub Projects のビューで、フィルターに AND/OR を使う高度な検索が GA になりました。Projects 利用者は個別ビューを維持する代わりに条件を組み合わせて必要な表示を作成できます。既存ビューの移行は不要です。

## Repository admins can archive pull requests

- 公開日 (UTC): `2026-07-16 19:01:09`
- リンク: <https://github.blog/changelog/2026-07-16-repository-admins-can-archive-pull-requests>

リポジトリ管理者が pull request を完全削除せずにアーカイブし、公開ビューから除外できるようになりました。アーカイブされた PR はクローズかつロックされるため、不要な履歴を整理する際は影響を確認して利用してください。

## REST API endpoints for Visual Studio Subscription management

- 公開日 (UTC): `2026-07-16 18:06:52`
- リンク: <https://github.blog/changelog/2026-07-16-rest-api-endpoints-for-visual-studio-subscription-management>

GitHub Enterprise Cloud 管理者向けに、Visual Studio Subscription の割り当てを REST API で取得・管理するエンドポイントが追加されました。大規模組織で割り当てを自動化する場合は、必要な権限と API 利用条件を確認して既存運用に組み込めます。

## Xcode 27 runner image now in public preview

## Improvements to secret scanning and public monitoring

- 公開日 (UTC): `2026-07-15 22:38:16`
- リンク: <https://github.blog/changelog/2026-07-15-improvements-to-secret-scanning-and-public-monitoring>
