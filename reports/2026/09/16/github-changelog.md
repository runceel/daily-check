## Enforce GitHub Advanced Security configurations

- 公開日 (UTC): `2026-09-15 19:31:58`
- リンク: <https://github.blog/changelog/2026-09-15-enforce-github-advanced-security-configurations>

Enterprise 管理者が、組織全体の GitHub Advanced Security 設定を強制適用できるようになりました。組織・リポジトリ管理者による上書きを防げるため、企業標準のセキュリティ設定を確実に維持したい環境が対象です。既存設定への影響を確認し、必要に応じて Enterprise 側で適用範囲を設定してください。

## GitHub Copilot suggests custom properties definitions

- 公開日 (UTC): `2026-09-15 19:07:47`
- リンク: <https://github.blog/changelog/2026-09-15-github-copilot-suggests-custom-properties-definitions>

GitHub Copilot が、組織リポジトリのカスタムプロパティ作成時に許可値を提案できるようになりました。GitHub Copilot Business および Copilot の対象プランでパブリックプレビューとして利用でき、プロパティ定義の標準化を支援します。利用する場合は、組織の設定画面でプレビュー機能と Copilot の利用条件を確認してください。

## SHA-1 in HTTPS on GitHub sunset

- 公開日 (UTC): `2026-09-15 16:47:20`
- リンク: <https://github.blog/changelog/2026-09-15-sha-1-in-https-on-github-sunset>

GitHub.com とパートナー環境で HTTPS 接続時の SHA-1 が予定どおり無効化されました。SHA-1 証明書や古い TLS／証明書検証に依存するクライアント、プロキシ、CI/CD 環境は接続できなくなる可能性があります。管理者は証明書チェーンと実行環境を確認し、SHA-256 以降に対応した構成へ移行してください。
