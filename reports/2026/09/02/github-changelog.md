## Enterprise Live Migrations from GHES to ghe.com generally available

- 公開日 (UTC): `2026-09-01 22:24:27`
- リンク: <https://github.blog/changelog/2026-09-01-enterprise-live-migrations-from-ghes-to-ghe-com-generally-available>

Enterprise Live Migrations が一般提供となり、GHES からデータレジデンシー対応の GitHub Enterprise Cloud へ、停止時間をほぼ発生させずにリポジトリを移行できます。GHES 管理者は、対象環境の前提条件と移行計画を確認して利用を開始してください。

## Set an expiration date for individual user budgets

- 公開日 (UTC): `2026-09-01 20:23:13`
- リンク: <https://github.blog/changelog/2026-09-01-set-an-expiration-date-for-individual-user-budgets>

個別ユーザーの予算に有効期限を設定でき、指定日になると GitHub が自動削除します。予算を一時的に割り当てる管理者は、期限付き設定で請求・利用管理を自動化できます。

## Copilot code review can now approve pull requests

- 公開日 (UTC): `2026-09-01 19:25:57`
- リンク: <https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests>

Copilot code review が承認可能な状態を通知し、管理者が許可した場合は PR の承認操作まで実行できます。既定では無効のため、導入する組織は権限・監査・ブランチ保護への影響を確認して明示的に有効化してください。

## Block users from discussion comments in personal repositories

- 公開日 (UTC): `2026-09-01 16:30:01`
- リンク: <https://github.blog/changelog/2026-09-01-block-users-from-discussion-comments-in-personal-repositories>

個人アカウント所有リポジトリの Discussions コメントから、ユーザーを直接ブロック／解除できるようになりました。管理者は問題のある参加者への対応を画面遷移なしで行え、既存の Issue・PR の制御と同じ運用に揃えられます。

## Claude Fable 5.1 is generally available in GitHub Copilot

- 公開日 (UTC): `2026-09-01 14:29:23`
- リンク: <https://github.blog/changelog/2026-09-01-claude-fable-5-1-generally-available-in-github-copilot>

Anthropic の Claude Fable 5.1 が GitHub Copilot で一般提供され、長時間の自律的なコーディングや知識作業を想定したモデルを選択できます。Copilot 利用者は、プラン・管理ポリシー・出力品質を確認してモデル選択肢に追加してください。

## GitHub CLI: Media in issues, pull requests, and comments

- 公開日 (UTC): `2026-09-01 12:35:59`
- リンク: <https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments>

GitHub CLI に繰り返し指定できる `--attach` フラグが追加され、ローカルの画像・動画をアップロードして Issue、PR、コメント本文へインライン参照できます。CLI で報告を作成する利用者は、添付処理を手動アップロードから置き換えられます。

## Selected GitHub Copilot models deprecated

- 公開日 (UTC): `2026-08-31 21:21:40`
- リンク: <https://github.blog/changelog/2026-08-31-selected-github-copilot-models-deprecated>

2026 年 9 月 1 日付で、複数の GitHub Copilot 体験（Chat、インライン編集、Ask/Agent モード、コード補完）から対象モデルが非推奨になりました。該当モデルを固定している利用者・管理者は、一覧を確認し後継モデルへ切り替えてください。
