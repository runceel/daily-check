## Retirement: Containerized data connector agent for the Microsoft Sentinel solution for SAP applications

- 公開日 (UTC): `2026-08-12 19:41:20`
- リンク: <https://azure.microsoft.com/updates?id=568457>

## [In preview] Public Preview: Azure Front Door mutual TLS 

- 公開日 (UTC): `2026-08-12 17:01:19`
- リンク: <https://azure.microsoft.com/updates?id=569251>

Azure Front Door で、バックエンドへ到達する前に X.509 クライアント証明書で認証する相互 TLS（mTLS）がパブリック プレビューになりました。B2B 接続や機密 API でクライアント証明書認証を検討している場合に、プレビューの制約を確認して評価できます。

## [In preview] Public Preview: Markdown for Agents in Azure App Service

- 公開日 (UTC): `2026-08-12 16:38:31`
- リンク: <https://azure.microsoft.com/updates?id=568979>

Azure App Service のコンテンツを、AI エージェントなどが取得しやすい Markdown 形式で返す機能がパブリック プレビューになりました。対応クライアントから Markdown を要求すると App Service が変換して返すため、エージェント連携を試すアプリはプレビュー条件を確認して導入できます。
