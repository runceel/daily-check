## Announcing: Migrate Azure Container Apps logging destination from Log Analytics to Azure Monitor

- 公開日 (UTC): `2026-10-28 17:52:51`
- リンク: <https://azure.microsoft.com/updates?id=577689>

Azure Container Apps の Log Analytics ログ出力先はレガシー扱いとなり、既存環境は引き続き動作しますが、今後の運用では Azure Monitor への移行が推奨されます。
Log Analytics を利用中の環境管理者は、既存設定が直ちに停止するわけではないものの、移行計画を立ててください。

## [In preview] Public Preview: Cross Tenant Restore with Azure Backup

- 公開日 (UTC): `2026-10-28 17:09:30`
- リンク: <https://azure.microsoft.com/updates?id=577117>

Azure Backup の Cross-Tenant Restore により、Azure VM のバックアップを別テナントへ復元できるようになり、既存のバックアップコピーを使った独立した復旧経路を確保できます。
複数テナントでの災害復旧やサイバーレジリエンスを強化したい組織向けのプレビュー機能です。利用にはプレビュー条件を確認し、復旧手順を検証してください。

## [Launched] Generally Available: Marketplace private offer enhancements 

- 公開日 (UTC): `2026-10-28 16:23:43`
- リンク: <https://azure.microsoft.com/updates?id=576547>

Microsoft Marketplace の対象となるプライベートオファーで、柔軟な請求や契約期間など、組織に合わせた価格・条件を適用しやすくする機能が一般提供されました。
Marketplace で調達する顧客と販売者は、対象オファーの条件・契約手順を確認して利用できます。既存契約の移行対応は告知されていません。
