## Announcing: New Windows App client-side endpoints for Azure Virtual Desktop

- 公開日 (UTC): `2026-09-14 18:24:04`
- リンク: <https://azure.microsoft.com/updates?id=571360>

2026年10月初旬から Windows App が Azure Virtual Desktop のクライアント通信に3つのワイルドカード FQDN を使用します。AVD のクライアント側ネットワークを許可リストで制御している管理者は、新しい宛先を追加確認してください。クラウド側要件には既に含まれているため、対象環境の接続要件を事前に更新します。

## [In preview] Public Preview: HTTP/3 over QUIC support in Azure Application Gateway

- 公開日 (UTC): `2026-09-14 17:55:00`
- リンク: <https://azure.microsoft.com/updates?id=571123>

Azure Application Gateway で HTTP/3 over QUIC のパブリックプレビューが始まり、接続確立時間・遅延・通信の回復性を改善できます。最新プロトコルを試す Web アプリ/API の運用者が対象です。プレビューのため、検証環境で互換性と監視を確認してから段階的に有効化してください。
