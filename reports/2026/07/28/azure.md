## [Launched] Generally Available: HTTP header insertion in Azure Firewall 

- 公開日 (UTC): `2026-07-27 16:54:36`
- リンク: <https://azure.microsoft.com/updates?id=568115>

Azure Firewall のアプリケーション規則から HTTP/HTTPS リクエストヘッダーを追加または上書きできる機能が一般提供されました。セキュリティ制御やテナント制限を Firewall で統一したい運用者は、既存のプロキシやアプリ側のヘッダー処理を見直し、必要な規則を段階的に適用できます。
