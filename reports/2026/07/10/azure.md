## [In preview] Public Preview: Manage Azure Chaos Studio from the Azure CLI

- 公開日 (UTC): `2026-07-09 22:57:33`
- リンク: <https://azure.microsoft.com/updates?id=567225>

Azure Chaos Studio のレジリエンス シナリオを、`az chaos` 拡張機能から作成・実行できるようになりました。REST 呼び出しや JSON の手作業構築を減らせるため、Chaos Studio を CLI や自動化パイプラインで管理する利用者に有用です。プレビュー機能のため、まずは検証環境で `az chaos setup` を試してください。

## [Launched] Generally Available: Open AI GPT-5.6 on Azure Databricks 

- 公開日 (UTC): `2026-07-09 20:21:12`
- リンク: <https://azure.microsoft.com/updates?id=567431>

OpenAI GPT-5.6 が Azure Databricks で一般提供され、Microsoft Foundry で購入したモデルを Model Serving Endpoint 経由で利用できるようになりました。Foundry と Azure Databricks の統合により、モデルの構築・デプロイ・管理を一貫して行えます。対象ワークロードでは既存のモデル提供構成と権限を確認したうえで利用を開始してください。
