## License data quality improvements

- 公開日 (UTC): `2026-08-13 19:14:12`
- リンク: <https://github.blog/changelog/2026-08-13-license-data-quality-improvements>

GitHub が npmjs.org や PyPI などのパッケージレジストリも参照して、依存関係グラフのライセンス情報を判定するようになりました。ライセンス表示の網羅性と精度が上がるため、依存関係やコンプライアンスを確認する利用者は追加設定なしで改善の恩恵を受けられます。

## Block users from comments in personal repositories

- 公開日 (UTC): `2026-08-13 19:02:46`
- リンク: <https://github.blog/changelog/2026-08-13-block-users-from-comments-in-personal-repositories>

個人アカウントが所有するリポジトリでは、Issue や Pull Request のコメントからユーザーを直接ブロック／解除できるようになりました。迷惑行為への対応を行う所有者は、対象コメントの操作メニューから設定でき、既存のリポジトリ設定変更や移行は不要です。

## Gemini 3.7 Flash is now available in GitHub Copilot

- 公開日 (UTC): `2026-08-13 14:00:53`
- リンク: <https://github.blog/changelog/2026-08-13-gemini-3-7-flash-is-now-available-in-github-copilot>

Google の Gemini 3.7 Flash が GitHub Copilot で順次利用可能になり、Web／アプリ開発やエージェント型タスクでの改善が見込まれます。対象ユーザーは Copilot のモデル選択画面で利用可否を確認し、応答品質や速度を既存モデルと比較して選択してください。
