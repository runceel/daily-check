## Global model policy generally available

- 公開日 (UTC): `2026-08-26 22:08:38`
- リンク: <https://github.blog/changelog/2026-08-26-global-model-policy-generally-available>

Copilot Business / Enterprise で、GA の Copilot モデルに対する既定モデルポリシーの適用が段階的に始まります。管理者は組織のモデル設定と利用者への影響を確認し、必要に応じて許可モデルを明示してください。

## GitHub Apps can now access enterprise billing data

- 公開日 (UTC): `2026-08-26 12:18:59`
- リンク: <https://github.blog/changelog/2026-08-26-github-apps-can-now-access-enterprise-billing-data>

Enterprise 所有者が GitHub App に enterprise billing data の権限を付与できるようになりました。請求情報を自動連携したい組織は、App の権限設定で必要最小限の billing 権限を選択し、アクセス範囲を監査してください。

## Rule insights dashboard generally available

- 公開日 (UTC): `2026-08-25 20:05:35`
- リンク: <https://github.blog/changelog/2026-08-25-rule-insights-dashboard-generally-available>

Rule insights dashboard がリポジトリと Organization の両レベルで **GA** になりました。ルールの評価・適用状況を可視化できるため、管理者はルールセットの意図しない拒否や未適用を確認しやすくなります。既存のルール運用に追加設定は不要ですが、監査に活用できます。

## GitHub Copilot app Customize tab is generally available

- 公開日 (UTC): `2026-08-25 20:05:26`
- リンク: <https://github.blog/changelog/2026-08-25-github-copilot-app-customize-tab-is-generally-available>

GitHub Copilot app の Customize タブが **GA** になり、MCP などチーム既存のツール・知識・ワークフローを Copilot に接続しやすくなりました。導入者は接続先の権限とデータ共有範囲を確認したうえで、必要なカスタマイズを設定してください。

## Block users directly from security advisories

- 公開日 (UTC): `2026-08-25 18:38:57`
- リンク: <https://github.blog/changelog/2026-08-25-block-users-directly-from-security-advisories>

公開リポジトリの security advisory ページから、対象ユーザーを直接ブロックできるようになりました。Organization または個人所有リポジトリの管理者は、悪用や迷惑行為への対応をページ内で完結できます。必要時にモデレーション手順へ組み込んでください。

## Push rules in rulesets now support path exceptions

- 公開日 (UTC): `2026-08-25 17:40:15`
- リンク: <https://github.blog/changelog/2026-08-25-push-rules-in-rulesets-now-support-path-exceptions>

Rulesets の push rules で、指定したファイルパスだけを例外にできるようになりました。管理者はリポジトリ全体の保護を維持しつつ、生成物や特定の管理ファイルなどを対象外にできます。既存ルールを見直し、例外が保護の抜け道にならないか確認してください。
