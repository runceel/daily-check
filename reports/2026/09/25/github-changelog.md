## Require proof of presence for high-impact actions

- 公開日 (UTC): `2026-09-24 20:28:33`
- リンク: <https://github.blog/changelog/2026-09-24-require-proof-of-presence-for-high-impact-actions>

GitHub Enterprise Cloud で、機密性の高い操作の前に IdP での再認証または MFA を要求する「proof of presence」がパブリックプレビューになりました。対象は Microsoft Entra ID を SAML/OIDC で利用する EMU 企業で、管理者は設定を確認し、トークン作成やセキュリティ設定変更などを追加認証で保護できます。
