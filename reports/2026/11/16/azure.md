## Retirement: Azure Data Share will be retired on November 12, 2029 

- 公開日 (UTC): `2026-11-13 19:54:45`
- リンク: <https://azure.microsoft.com/updates?id=578818>

Azure Data Share は **2029 年 11 月 12 日に廃止予定**です。利用中のデータ共有ワークロードは、それまでに Microsoft Fabric の External data sharing、Cross tenant delegated shortcuts、IQ share、またはデータソースに適した共有機能へ移行してください。

## [In preview] Public Preview: JWT validation with Azure Front Door Auth Policy 

- 公開日 (UTC): `2026-11-12 22:36:37`
- リンク: <https://azure.microsoft.com/updates?id=577673>

Azure Front Door Premium の Auth Policy で、Microsoft Entra ID が発行した bearer token を API や Web アプリに届く前のエッジで検証する JWT 検証機能がパブリックプレビューになりました。Front Door 側での認証処理を試したい利用者向けの告知であり、プレビュー機能として評価できます。

## [Launched] Generally Available: Azure Front Door mutual TLS authentication

- 公開日 (UTC): `2026-11-12 22:27:35`
- リンク: <https://azure.microsoft.com/updates?id=577678>

Azure Front Door Premium の相互 TLS（mTLS）認証が **一般提供 (GA)** になり、X.509 クライアント証明書でアプリや API への接続元を認証できます。B2B、IoT、金融などでクライアント証明書による保護を必要とする利用者は、GA 機能として導入を検討できます。

## [In preview] Public Preview: Auto scaling of ingestion limits in Azure Monitor workspace

- 公開日 (UTC): `2026-11-12 18:23:52`
- リンク: <https://azure.microsoft.com/updates?id=578207>

Azure Monitor Workspace (AMW) で、観測された利用状況に応じてワークスペース単位の取り込み上限を自動調整する機能がパブリックプレビューになりました。有効化を検討する運用者は、既存の取り込み量やクォータ管理への影響を確認しながら評価してください。

## [In preview] Public Preview: SQL performance monitoring for Azure SQL Managed Instance

- 公開日 (UTC): `2026-11-12 16:59:40`
- リンク: <https://azure.microsoft.com/updates?id=574158>

Azure SQL Managed Instance 向けに、Microsoft 管理のパフォーマンス監視がパブリックプレビューとして提供されました。独自スクリプトや複数の監視ツールで重要な SQL MI ワークロードを監視している利用者は、プレビューを評価し、既存の監視方法と比較できます。
