## [In preview] Public Preview: Azure Databricks Private network gateway

- 公開日 (UTC): `2026-10-16 16:59:02`
- リンク: <https://azure.microsoft.com/updates?id=576556>

Azure Databricks の serverless compute から、単一のマネージド gateway を介して VNet 内および推移的に接続されたネットワークのリソースへ接続できる機能が Public Preview になりました。プライベートネットワーク上のデータソースを serverless workload から利用する組織は、プレビュー条件とネットワーク要件を確認して評価できます。プレビュー機能のため、既存構成の移行は不要です。

## [Launched] Generally Available: External key management for Azure Key Vault Managed HSM

- 公開日 (UTC): `2026-10-16 16:50:27`
- リンク: <https://azure.microsoft.com/updates?id=574296>

Azure Key Vault Managed HSM の外部キー管理が、Azure パブリックリージョン全域で GA になりました。規制・データ主権要件により、キー暗号化キーを自組織で物理的に管理したい組織は、本番環境で Azure サービスのデータ保護に利用できます。該当する場合は対応サービス、リージョン、キー管理の運用要件を確認して導入を検討してください。
