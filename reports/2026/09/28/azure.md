## [In preview] Public Preview: Azure HorizonDB supports PostgreSQL 18

- 公開日 (UTC): `2026-09-25 18:07:26`
- リンク: <https://azure.microsoft.com/updates?id=573048>

Azure HorizonDB のパブリックプレビューで PostgreSQL 18 が利用可能になりました。フルマネージドの PostgreSQL 互換データベースを評価するチームは、新バージョンとの互換性や必要な機能をプレビュー環境で確認できます。プレビューのため、本番利用を前提とした移行対応は不要です。
