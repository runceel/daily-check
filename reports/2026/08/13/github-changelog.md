## Agent Plugins 1.0 in VS Code, Copilot CLI, and the Copilot app

- 公開日 (UTC): `2026-08-12 18:39:11`
- リンク: <https://github.blog/changelog/2026-08-12-agent-plugins-1-0-in-vs-code-copilot-cli-and-the-copilot-app>

Agent Plugins 1.0 により、互換性のある VS Code、Copilot CLI、Copilot app などのエージェント クライアントで同じプラグインを共有できるようになりました。複数クライアント向けに拡張を配布する開発者は、対応仕様を確認して一度作成したプラグインを各環境で利用できます。
