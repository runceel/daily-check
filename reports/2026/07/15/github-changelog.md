## Dependabot version updates introduce default package cooldown

- 公開日 (UTC): `2026-07-14 16:42:59`
- リンク: <https://github.blog/changelog/2026-07-14-dependabot-version-updates-introduce-default-package-cooldown>

Dependabot のバージョン更新 PR は、レジストリ公開後少なくとも 3 日待ってから作成される既定のクールダウンが導入されました。更新の即時性が必要なリポジトリは、Dependabot 設定で既定値との違いを確認してください。

## Security reviews now available in the GitHub Copilot app

- 公開日 (UTC): `2026-07-14 12:54:12`
- リンク: <https://github.blog/changelog/2026-07-14-security-reviews-now-available-in-the-github-copilot-app>

GitHub Copilot アプリで進行中のコード変更に対するセキュリティレビューを実行できるようになり、`/security-review` がパブリックプレビューで提供されます。導入時はレビュー結果を人手で確認し、既存のセキュリティ審査を置き換えない運用にしてください。
