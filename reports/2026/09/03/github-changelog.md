## Enterprise-managed settings support any default model

- 公開日 (UTC): `2026-09-02 18:51:12`
- リンク: <https://github.blog/changelog/2026-09-02-enterprise-managed-settings-support-any-default-model>

Enterprise 管理者が、GitHub Copilot の新しい会話で使う既定モデルを任意の利用可能モデルから指定できるようになりました。組織全体で用途やガバナンスに合うモデルを標準化したい場合に設定を見直す項目で、既存の会話には影響せず、利用者による移行作業もありません。

## Content exclusions generally available in Copilot app and CLI

- 公開日 (UTC): `2026-09-02 18:14:23`
- リンク: <https://github.blog/changelog/2026-09-02-content-exclusions-generally-available-in-copilot-app-and-cli>

GitHub Copilot app と Copilot CLI が、Enterprise・Organization・Repository 管理者の content exclusion policy を正式に尊重するようになりました。除外ファイルはコンテキストに利用されないため、機密情報や生成対象外コードの保護が強化されます。既にポリシーを設定済みなら追加移行は不要ですが、管理者は除外範囲が意図どおりか確認してください。
