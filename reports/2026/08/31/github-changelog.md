## GitHub Classroom deprecated

- 公開日 (UTC): `2026-08-27 22:42:40`
- リンク: <https://github.blog/changelog/2026-08-27-github-classroom-deprecated>

GitHub Classroom は **2026 年 8 月 28 日付で非推奨**となり、Web サイト、API、関連サービスが廃止されました。授業や課題で利用していた教育機関は、GitHub が案内するパートナーソリューションへ移行し、既存の連携や運用手順を直ちに見直す必要があります。

## Actions retention will cover checks, workflow runs, and statuses

- 公開日 (UTC): `2026-08-27 21:50:39`
- リンク: <https://github.blog/changelog/2026-08-27-actions-retention-will-cover-checks-workflow-runs-and-statuses>

**2026 年 10 月 1 日から**、Actions の checks、workflow runs、statuses にも、既存の artifact／ログ保持期間設定が適用されます。CI の監査や再現性に必要な期間を確保したい組織は、期限前に Actions retention 設定とストレージ影響を確認してください。

## Close all open contributions authored by a blocked user

- 公開日 (UTC): `2026-08-27 16:30:52`
- リンク: <https://github.blog/changelog/2026-08-27-close-all-open-contributions-authored-by-a-blocked-user>

個人アカウントまたは組織でユーザーをブロックする際、そのユーザーが作成した未完了の Issue、Discussion、PR を自動クローズできるようになりました。モデレーターはブロック時のオプションとして有効化できるため、記録保持や引き継ぎが必要な運用では適用前に確認してください。

## Enterprise-managed settings now support autoUpdate for plugin marketplaces

- 公開日 (UTC): `2026-08-27 01:52:19`
- リンク: <https://github.blog/changelog/2026-08-26-enterprise-managed-settings-now-support-autoupdate-for-plugin-marketplaces>

Enterprise managed settings の `extraKnownMarketplaces` で `autoUpdate: true` を指定すると、個別のプラグインマーケットプレースを自動更新の対象にできます。管理者は対象マーケットプレースと更新元を明示したうえで設定を追加し、対応クライアントでの更新タイミングと変更管理を確認してください。
