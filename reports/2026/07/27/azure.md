## [In preview] Public Preview: Azure DDoS Protection custom policy

- 公開日 (UTC): `2026-07-23 16:47:24`
- リンク: <https://azure.microsoft.com/updates?id=568063>

Azure DDoS Protection のカスタム ポリシーがパブリック プレビューとなり、保護対象の Standard Load Balancer フロントエンド IP ごとに DDoS 軽減しきい値を制御できるようになりました。リソースごとのトラフィック特性に合わせた検出設定が必要な利用者はプレビュー環境で評価できますが、既存構成に直ちに必要な移行はありません。

## [In preview] Public Preview: Standard service endpoint 

- 公開日 (UTC): `2026-07-22 16:57:10`
- リンク: <https://azure.microsoft.com/updates?id=561475>

Private Link ファミリの Standard service endpoint がパブリック プレビューとなり、IaaS ワークロードから Azure PaaS サービスへ、従来のスケールや管理上の制約を抑えて接続できる選択肢が追加されました。大規模なサービス エンドポイント構成を管理する利用者は新規環境で適合性を評価できますが、プレビュー段階のため既存接続を直ちに切り替える必要はありません。
