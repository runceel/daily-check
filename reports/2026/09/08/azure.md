## [Launched] Generally Available: Azure Virtual Network Manager IPAM in additional Azure regions 

- 公開日 (UTC): `2026-09-03 17:17:08`
- リンク: <https://azure.microsoft.com/updates?id=570557>

Azure Virtual Network Manager の IP アドレス管理（IPAM）が、米国政府リージョン（バージニア、テキサス、アリゾナ）と中国リージョン（North 3、East 3）でも **GA** になりました。  
これらのリージョンで複雑なネットワークを運用する利用者は、IPAM を使ってアドレス空間の割り当て・追跡を一元化できます。新規導入や既存環境への適用を検討する場合は、対象リージョンでの提供条件と料金を確認してください。
