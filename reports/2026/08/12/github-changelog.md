## GitHub billing in India now supports automatic recurring payments

- 公開日 (UTC): `2026-08-10 14:00:58`
- リンク: <https://github.blog/changelog/2026-08-10-github-billing-in-india-now-supports-automatic-recurring-payments>

## Custom thread subscriptions are being deprecated

- 公開日 (UTC): `2026-08-10 12:45:49`
