## [Launched] Generally Available: Large OS Disk Encryption for Azure Confidential VM migrations

- 公開日 (UTC): `2026-10-29 21:19:52`
- リンク: <https://azure.microsoft.com/updates?id=578850>

Azure Confidential VM への移行シナリオで Large OS Disk Encryption (LOSDE) が GA となり、OS ディスクを保護したまま大規模な本番ワークロードを機密コンピューティングへ移行しやすくなりました。
対象となる移行を計画中の組織は、この機能を利用できる構成を確認してください。告知は GA の案内であり、既存環境に対する一律の移行作業は示されていません。

## [Launched] Generally Available: HTTP DDoS ruleset for Azure Front Door Premium WAF

- 公開日 (UTC): `2026-10-29 17:09:49`
- リンク: <https://azure.microsoft.com/updates?id=578681>

Azure Front Door Premium の WAF で HTTP DDoS ruleset が GA になりました。割り当てるとプロファイルごとに通常トラフィックを学習し、攻撃と判断したトラフィックを選択的に緩和するレイヤー 7 保護を提供します。
HTTP 層の DDoS 対策を見直す運用者は WAF ポリシーへの割り当てを検討し、監視方法も確認してください。告知は新機能の GA で、既存構成の強制変更は示されていません。

## [Launched] Generally Available: Azure MCP Server 3.0

- 公開日 (UTC): `2026-10-29 17:04:58`
- リンク: <https://azure.microsoft.com/updates?id=578662>

Azure MCP Server 3.0 が GA となり、Model Context Protocol (MCP) を介して AI エージェントや開発ツールから Azure を扱う機能が拡張されました。告知では Infrastructure as Code 分野の Azure Terraform 対応などが挙げられています。
Azure MCP Server を利用する開発者は、3.0 の新機能と利用方法を確認して導入を検討してください。RSS の説明は途中で切れており、個別機能の詳細や既存構成への移行要否はリンク先で確認が必要です。
