## Open source license compliance generally available

- 公開日 (UTC): `2026-10-16 14:00:32`
- リンク: <https://github.blog/changelog/2026-10-16-open-source-license-compliance-generally-available>

GitHub Enterprise Cloud で、依存関係のライセンスをルールセットで一元管理・検査する Open source license compliance が GA になりました。組織のライセンスポリシーを大規模に適用したい管理者は、ルールセットを設定して利用できます。導入時は既存のポリシーと検査対象を確認してください。

## Xcode 27 runner image generally available

- 公開日 (UTC): `2026-10-16 04:36:30`
- リンク: <https://github.blog/changelog/2026-10-15-xcode-27-runner-image-generally-available>

GitHub Actions の GitHub-hosted runner で、Xcode 27 イメージが Public Preview から GA になり、Apple アプリのビルド・テストに利用できます。既存のワークフローで新しい Xcode を使う場合は、runner image の指定とビルド互換性を確認して切り替えてください。

## Multi-repository support and other improvements for GitHub in Slack and Teams

- 公開日 (UTC): `2026-10-16 02:16:35`
- リンク: <https://github.blog/changelog/2026-10-15-copilot-in-slack-and-teams-adds-model-and-repository-updates>

Slack と Teams の @GitHub で、1 つの会話から複数リポジトリをまたいで Issue 作成、PR 起票、調査を行えるようになりました。複数リポジトリにまたがる開発チームは、会話内で対象リポジトリを指定して活用できます。新機能の利用にあたり、既存ワークフローの移行は不要です。
